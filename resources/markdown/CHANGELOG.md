# Changelog
All notable changes to BlazeMail will be documented in this file.

## [v0.3.2] - 2024-01-15

### Added
- **Email Templates**: New drag-and-drop email template builder
- **Advanced Analytics**: Track open rates, click-through rates, and engagement metrics
- **Team Collaboration**: Invite team members and manage permissions
- **API Webhooks**: Real-time notifications for email events

![New Dashboard Screenshot](images/draw.png "New Dashboard Interface")

### Improved
- **Performance**: 40% faster email delivery times
- **Dashboard**: Redesigned analytics dashboard with better data visualization
- **Mobile App**: Enhanced mobile experience with offline support
- **Search**: Improved search functionality across all email campaigns

> **Note**: The new dashboard provides real-time insights into your email campaigns with interactive charts and detailed metrics.

### Fixed
- Fixed issue with email scheduling in different timezones
- Resolved attachment upload problems for files over 10MB
- Fixed dashboard loading issues on slower connections
- Corrected email preview rendering for Outlook clients

## [v0.3.1] - 2024-01-02

### Added
- **Dark Mode**: Full dark mode support across the entire application
- **Email Automation**: Create automated email sequences and drip campaigns
- **Custom Domains**: Connect your own domain for branded email sending
- **A/B Testing**: Split test your email campaigns for better performance

![Dark Mode Preview](dark-mode-preview.png "Dark Mode Interface")

### Improved
- **Editor**: Enhanced email editor with better formatting options
- **Deliverability**: Improved email deliverability rates by 25%
- **Loading Times**: Reduced initial page load time by 60%
- **Accessibility**: Better screen reader support and keyboard navigation

### Fixed
- Fixed email template saving issues
- Resolved contact import problems with CSV files
- Fixed notification settings not persisting
- Corrected timezone display issues in campaign scheduling

## [v0.3.0] - 2023-12-18

### Added
- **Contact Segmentation**: Advanced contact filtering and segmentation tools
- **Email Personalization**: Dynamic content based on subscriber data
- **Integration Hub**: Connect with popular tools like Shopify, WordPress, and Zapier
- **Advanced Reporting**: Detailed campaign performance reports and insights

### Improved
- **User Interface**: Complete UI overhaul with modern design
- **Email Builder**: Drag-and-drop email builder with 50+ new templates
- **Performance**: Database optimizations for faster query responses
- **Security**: Enhanced security measures and two-factor authentication

### Fixed
- Fixed bulk email sending limitations
- Resolved image upload issues in email templates
- Fixed contact list synchronization problems
- Corrected email preview inconsistencies
