# Changelog
All notable changes to BlazeMail are documented here.

## [v1.0.0] - 2024-08-01  
**🚀 Public Beta Launch**

![BlazeMail Beta Launch](images/banners/v1.png "BlazeMail Public Beta Launch")

### Added
- **AI Cold Email Generator** — Powered by GPT + Groq  
- **Smart Personalization** — Dynamic intros, objections, and CTAs per lead  
- **Multi-Variant Output** — Generate multiple versions instantly  
- **Fast Mode** — 10+ personalized emails in <30s  
- **Live Editor** — Real-time preview with tone & structure analysis  
- **Usage Credit System** — Transparent tracking per generation  
- **Minimalist UI** — Clean, fast, no fluff  
- **Dark Mode** — For power users & night grinders  

### Improved
- **Prompt Tuning** — More human tone, better intent awareness  
- **Email Framework** — Clearer subject lines, stronger hooks, soft CTAs  
- **Speed** — Major latency drop thanks to Groq integration  

### Fixed
- Prompt repetition and formatting bugs  
- Groq API throttling under load  
- Mobile UI scaling issues
